## 1. Project Overview

The **Customer Intelligence & Support Copilot (Teaching Kit)** is an educational, end-to-end machine learning and agentic application simulating a customer operations platform for an Instamart-style quick-commerce delivery business ([README.md](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/README.md#L1-L7)). It encompasses a full analytical and AI lifecycle: synthetic data generation, an auditing and ETL pipeline writing clean tables into an embedded SQLite database, analytical SQL reporting, customer RFM segmentation (K-Means/PCA), a leakage-aware churn/lapse classification model (Logistic Regression & Random Forest via GridSearchCV), a privacy-first support ticket triage pipeline with regex PII redaction and token guardrails, TF-IDF policy document retrieval (RAG), and a bounded ReAct refund agent with database order lookup and audit ledger logging. The stack is built entirely on Python 3.11+, pandas, numpy, scikit-learn, joblib, and SQLite3, utilizing an offline deterministic mock LLM ([mock_llm.py](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/mock_llm.py#L1-L68)) that requires zero external API keys, cloud credits, or network calls.

### Module Responsibilities

- **Root Scripts:**
  - [`generate_data.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/generate_data.py#L1-L135): Standalone synthetic data generator. Uses fixed pseudo-random seeds (`random.Random(42)`) to generate 1,200 customer profiles, 40 catalogue products, ~15,000 orders with synthetic data anomalies, 164 customer support tickets, 5 company policy text files, and 14 evaluation QA benchmarks.
  - [`mock_llm.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/mock_llm.py#L1-L68): Standalone, zero-network mock LLM engine. Implements keyword-based ticket classification with simulated 503 transient errors, policy document question answering using term frequency overlap, and tool-calling agent simulation following OpenAI-style message schemas.
  - [`run_project.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/run_project.py#L1-L20): Sequential batch execution entry point running Data Pipeline (Part A), Customer Modeling (Part B), Ticket Triage (Part C), and Policy RAG (Part D).
  - [`requirements.txt`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/requirements.txt#L1-L4): Minimal dependency list pinning `pandas>=2.0`, `numpy>=1.24`, `scikit-learn>=1.3`, and `joblib>=1.3`.
- **`src/` Package:**
  - [`src/data_pipeline.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/src/data_pipeline.py#L1-L82): Audits raw CSVs for anomalies, cleans city/gender text casing, imputes missing ages via city medians, resolves pending vs final order duplicates, imputes missing amounts from catalogue pricing, cleans negative delivery durations, validates assertions, and writes clean data to `data/clean/` and `data/instamart.db`.
  - [`src/customer_models.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/src/customer_models.py#L1-L82): Implements RFM metric extraction, fits K-Means clustering ($K=2\dots8$) with silhouette scores and PCA explained variance analysis, segments customers into Premium/Frequent/At Risk, and trains a leakage-aware churn/lapse model (temporal split: features strictly before September 2025; label evaluates September 2025) comparing Logistic Regression and Random Forest with GridSearchCV, saving to `outputs/lapse_model.joblib`.
  - [`src/triage.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/src/triage.py#L1-L66): Pre-prompt privacy guardrails: enforces input token limits, masks emails, Indian 10-digit phone numbers, and Order IDs via regex, handles transient LLM failures with exponential backoff and jitter, validates JSON schema responses, and routes tickets to appropriate queues (`security_team`, `premium_desk`, `support_queue`, or `human_review`).
  - [`src/policy_rag.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/src/policy_rag.py#L1-L37): Implements text chunking with sliding window overlap, computes TF-IDF embeddings using Scikit-Learn `TfidfVectorizer`, retrieves top-$k$ relevant policy passages via cosine similarity, grounds the offline policy assistant, and benchmarks retrieval accuracy against `policy_eval.csv`.
  - [`src/refund_agent.py`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/src/refund_agent.py#L1-L48): Implements a bounded ReAct agent tool loop with tools: `get_order` (SQLite lookup), `search_policy` (RAG search), `calculate_refund` (rule logic), `issue_refund` (automatic ledger entry for amounts $\le 1000$ INR), and `escalate_to_human` (amounts $> 1000$ INR). Enforces timeout and iteration budgets, checkpoints state to `state/<run_id>.json`, and appends transactions to `outputs/refund_ledger.jsonl`.
- **`notebooks/`:**
  - [`notebooks/Customer_Intelligence_Support_Copilot.ipynb`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/notebooks/Customer_Intelligence_Support_Copilot.ipynb): Interactive pedagogical notebook designed for classroom instruction, executing each phase interactively with rich displays and discussion prompts.
- **`sql/`:**
  - [`sql/queries.sql`](file:///c:/saved%20files/Capstone%20Project/instamart_customer_copilot_teaching_kit/sql/queries.sql#L1-L46): Seven reference SQL learning patterns: WHERE vs. HAVING, multi-table JOINs, subqueries, LEFT JOINs for missing records, Common Table Expressions (CTEs), ranking window functions (`RANK`, `DENSE_RANK`, `ROW_NUMBER`), and cumulative running totals.

## 11. How to Run

### 1. Full Pipeline Execution (CLI)

Executes all analytical and modeling steps sequentially (Part A: Clean & DB Load $\to$ Part B: Segments & Lapse Model $\to$ Part C: Ticket Triage $\to$ Part D: Policy RAG):

```bash
python run_project.py
```

*Expected output:* Checkpoints passed message, K-Means cluster diagnostics, PCA explained variance, Random Forest CV F1 scores, ticket triage summary, and policy retrieval accuracy evaluation table.

---

### 2. Individual Stage Execution

#### Stage 1: Data Generation
Generates raw synthetic CSVs (`data/raw/`) and policy documents (`data/policies/`):
```bash
python generate_data.py
```

#### Stage 2: Data Pipeline & SQLite Ingestion (Part A)
Audits raw anomalies, executes cleaning and imputation rules, verifies invariants, and populates `data/instamart.db`:
```bash
python src/data_pipeline.py
```

#### Stage 3: RFM Customer Segmentation & Lapse Modeling (Part B)
